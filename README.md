# battlecode19-vibe

An autonomous attempt at a champion bot for Battlecode 2019 ("Crusade"), JavaScript, on the pinned engine `bc19` 0.4.7.

| File | What |
|---|---|
| `PROMPTS.md` | every owner prompt, verbatim (PDT) |
| `CLAUDE.md` | session rules |
| `RULES.md` | the game, checked against the engine source |
| `TRAINING_ALGORITHM.md` | how the bot gets stronger (year-agnostic) |
| `HANDOFF.md` | current state, how to run everything, open directions |
| `TRAINING_LOG.md` | append-only log of every attempt |
| `LEARNINGS.md` | confirmed lessons, each with its measurement |
| `ACCESS.md` | how to reach the private 2019 competition replica (galaxy) |
| `src/bot/` | the bot (one module per role; `world.js` is the side-symmetric canonical frame; `config.js` holds every behaviour switch) |
| `progress/` | progress charts and tables, regenerated by `tools/progress-refresh.sh` (below) |
| `bots/` | frozen builds (`ROSTER.tsv`) |
| `tools/` | build, runner, batch, replay reader, basics battery, symmetry check, paired read, map corpus, VM helper, `galaxy19/` replica, `bench/` field discovery, `progress/` ratings and charts |
| `test/` | unit tests: `tools/unit-tests.sh` |
| `maps/corpus.tsv` | features of map seeds 1-3000 |
| `research/prior/` | digests of earlier seasons' projects |

## Progress

`progress/` shows how strong each build is, from every recorded game: local batches on the VM and the galaxy replica.

| File | What |
|---|---|
| [`progress/ELO.md`](progress/ELO.md), `elo.png` | Bradley-Terry ratings (Elo scale, 95% intervals) of every build, candidate and field bot; field score = expected score against the rated field |
| `progress/progress.png` | the accepted builds in order: rating, and expected field score % |
| [`progress/ATTEMPTS.md`](progress/ATTEMPTS.md) | every attempt and its funnel stages (source `progress/attempts.csv`; `tools/progress/attempts.py set`) |
| [`progress/ladder.md`](progress/ladder.md), `ladder.png` | snapshot of the replica's Rankings page |
| [`progress/rating-history.md`](progress/rating-history.md), `rating-history.png` | our team's replica rating after each rated match, submissions marked; below, the BT rating (progress/ELO.md) of the build behind the rated matches |
| `progress/games.csv` | every game: run, seq, teamA, teamB, map, winner, rounds, reason, seed, a_side, time |

Refresh everything (pulls the VM's batch files and the replica's data, refits, redraws; safe to rerun):
`tools/progress-refresh.sh`, then commit `progress/`. Charts use matplotlib from `.venv-progress` (created by the
script from the hash-locked `tools/progress/requirements.txt`).
