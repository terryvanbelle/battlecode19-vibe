# Attempts

Every bot attempt, oldest first, with its score at each stage of the acceptance funnel. Generated by `tools/progress/attempts.py render` from `progress/attempts.csv`; update a row with `tools/progress/attempts.py set <codename> field=value ...`, never by editing this file.

**The funnel** (TRAINING_ALGORITHM.md §2):
1. **Local h2h vs incumbent**: the candidate against the accepted build on random map seeds, both sides, on the VM (`tools/batch.js`, timescale 2 since v3; round-0 init failures retried, not counted).
2. **Reference batches**: the same against fixed references (the starter bot `bots/example`, older builds, sparring partners) as a screen.
3. **Replica**: submitted to the galaxy replica (`tools/galaxy19/contest19.py submit`); its games there (`progress/ELO.md`, `progress/rating-history.md`).
4. **Outcome**: accepted (the roster name it was frozen as), rejected, dropped, in progress, queued; sparring partners are training opponents, not attempts at the bot.

**Recorded games (auto)** is computed at each render from `progress/games.csv`: the attempt's W-L against every opponent (local unless marked replica), under its player name (`build`; candidates are `cand:<codename>`). It includes batches still running at the last refresh.
